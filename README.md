# Networkwalks---Cybersecurity-Internship-lab

## About This Repository

Welcome to my cybersecurity internship learning repository. This repository documents my practical learning journey during the **Cybersecurity Internship at Networkwalks IT Solutions & Training**.

The main objective of this repository is to document cybersecurity lab setup, practical exercises, technical learning, screenshots, and security assessment reports throughout the internship.

## Internship Learning Roadmap

### Week 1 — Cybersecurity Lab Setup
- Setting up a cybersecurity and penetration-testing lab.
- Preparing a Kali Linux testing environment.
- Configuring a Windows target environment.
- Preparing an Android testing environment.
- Understanding lab networking and connectivity verification.

### Week 2 — Footprinting, Scanning & Reporting
- Learning footprinting and reconnaissance.
- Practicing network scanning using tools such as Nmap.
- Exploring Maltego for information gathering.
- Documenting observations and preparing security reports.

### Week 3 — Security Testing & Attack Techniques
- Learning password security and password auditing concepts.
- Exploring tools such as John the Ripper and Metasploit.
- Practicing security testing in authorized lab environments.
- Understanding attack techniques and their defensive implications.

### Week 4 — Practical Project
**Offensive Security Track**
- Performing an authorized penetration-testing project.
- Documenting findings, evidence, impact, and remediation.

**Blue Team / SOC Track**
- Setting up Wireshark.
- Capturing and analyzing network traffic.
- Documenting observations in a security analysis report.
